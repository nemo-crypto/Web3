# 应用、治理与商业模式

[课程首页](../../README.md) · [所有阶段](../README.md)

用资产、数据、权利和真实需求比较 NFT、DAO、游戏、社交和基础设施。

**适合** 产品与研究人员

**阶段验收** 能画出应用的用户、收入、治理和退出关系。
