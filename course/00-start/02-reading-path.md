# 怎样用这门课

[课程首页](../../README.md) · [本阶段](README.md)

> **学完能做到**：选择学习路线、检查前置知识并安排第一份练习。

## 先看一个场景

有人只想弄懂钱包弹窗，有人要实现支付对账，有人要做 DApp。三者可以共享交易基础，然后进入不同分支。

阅读时先看案例发生了什么，再读解释和自测。会复述一段流程、能做出一道练习，就可以继续。读过但暂时画不出流程时，把课留在待完成，等下一遍复盘再标记。

## 第一次阅读按这六站走

每一站完成右边那一件事即可往下走。遇到英文缩写时，先看它在流程里做什么，回头再查全称。

| 顺序 | 阅读 | 通过标准 |
| --- | --- | --- |
| 1 | [看懂公链的五个角色](../01-blockchain/01-public-blockchains.md) | 能说清钱包、节点和区块浏览器分别做什么 |
| 2 | [跟一笔转账看到回执](../01-blockchain/07-transaction-lifecycle.md) | 能区分已发出、已执行和可入账 |
| 3 | [读一份模拟浏览器记录](../01-blockchain/09-read-an-explorer.md) | 找到网络、币种、到账方和确认状态 |
| 4 | [看懂连接和授权](../02-wallets/04-connect-wallet.md)与[签名弹窗](../02-wallets/03-signatures-approvals.md) | 用自己的话复述每个弹窗批准了什么 |
| 5 | [分清原生币和代币](../05-payments/01-token-standards.md) | 能解释为什么有代币余额还可能付不了网络费 |
| 6 | [完成一次模拟收款](../05-payments/03-payment-reconciliation.md) | 用 12.5 + 12.5 的示例对账，知道遇到重复事件怎么处理 |

第六站可以换成[模拟兑换](../06-defi/01-defi-overview.md)。能完整讲清一次操作以后，再按自己的目标读开发、市场或治理。忘了某个概念，直接查[中文术语速查](../10-projects/05-glossary.md)。

## 六站读完，选一件事做到底

| 想学什么 | 先读 | 再做 |
| --- | --- | --- |
| 做收款页面 | [稳定币为何有市场价和赎回规则](../05-payments/02-stablecoin-models.md)、[收银台怎样确认发货](../05-payments/12-checkout-and-fulfillment.md) | 按顺序处理分笔付款、重复通知、撤回 |
| 理解跨链延迟 | [Rollup 提现怎样进入领取状态](../04-scaling/10-rollup-withdrawal-operation.md) | 模拟一份「源链已扣、目标还没到」的工单 |
| 开发票务或权益 | [本地合约怎样测试一次核销](../03-development/02-solidity-testing.md)、[页面怎样显示交易状态](../03-development/09-transaction-ui-state-machine.md) | 为同一张票写两次提交后的预期记录 |

这三题可以在[新手跟做练习](../../reference/beginner-workbook.md)找到逐步答案。练习册还可以用来练钱包权限核对、商户净收和盘口恢复。先写下你的判断，再展开检查。

## 动手练习

任选转账、连接钱包、兑换或购买门票。把它画成三格：**我做了什么 → 在哪里查结果 → 还有什么没完成**。比如转账后取得哈希，下一格写「用哈希查回执」，第三格写「还要等商户入账」。再用[业务案例库](../../reference/business-cases.md)检查你能否选择合适的下一步。
