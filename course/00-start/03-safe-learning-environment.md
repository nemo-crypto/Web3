# 准备模拟环境与阅读资料

[课程首页](../../README.md) · [本阶段](README.md)

> **学完能做到**：准备可复现的离线数据、测试钱包和资料版本。

## 先看一个场景

同一篇资料用的是某条测试链，视频里的合约地址却属于旧的部署。照抄地址可能查到空代码或错误资产。

## 核心原理

把可复现环境分成模拟数据、本地节点和公共测试网络。记录网络、工具版本、区块高度和部署地址；示例账号与生产账号分开。

## 需要区分的概念

模拟适合算术和状态机；本地节点适合控制区块和异常；公共测试环境适合观察钱包和 RPC 接入。

## 动手练习

准备一份包含网络 ID、工具版本、地址来源与单位的实验记录。先使用离线样例，再按练习需求切到本地节点。

## 自测

同一个 0x 地址在两条链上怎样区分？

<details>
<summary>查看参考答案</summary>

把网络 ID 与地址一起保存和显示。同一地址可在不同链对应不同资产、合约或空账户。

</details>
