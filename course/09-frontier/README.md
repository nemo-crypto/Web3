# 智能体、隐私与前沿专题

[课程首页](../../README.md) · [所有阶段](../README.md)

辨认前沿提案的信任依赖、授权范围和验证条件。

**适合** 进阶读者

**阶段验收** 能写出一个智能体付款或隐私证明案例的接口与信任边界。

## 课程目录

| 课程 | 学习成果 |
| --- | --- |
| [AI 与 Web3 的应用分工](01-ai-web3.md) | 识别真正的技术结合点，区分链上记录、计算验证和模型质量 |
| [x402 与 API 付款](02-x402.md) | 理解 HTTP 402、付款授权、验证与结算的区别，并设计不会重复扣款的智能体消费流程 |
| [ERC-8004 与智能体身份](03-agent-identity.md) | 区分 Agent 身份、声誉、验证与真实能力，理解为什么链上评分不能消除欺诈 |
| [AP2 与智能体商务授权](04-agent-commerce.md) | 区分购物意图、订单授权和付款授权，理解 AP2、x402 与 Agent 身份机制的分工 |
| [数字身份与真人证明](05-identity-and-pop.md) | 区分身份、账户控制、真人性、唯一性与实名，理解匿名证明如何限制重复参与 |
| [zkTLS 与可验证链下数据](06-zktls.md) | 理解 TLS 会话、来源证明、选择性披露与业务真实性的区别，判断链下数据如何进入链上决策 |
| [FHE、MPC、TEE 与隐私计算](07-fhe-and-privacy.md) | 区分 FHE、ZK、MPC 与 TEE，理解密文计算、结果正确性和解密权限是不同问题 |
| [后量子签名与账户迁移](08-post-quantum.md) | 区分签名、密钥协商和哈希的风险，理解后量子算法与链上迁移为什么不是同一件事 |
| [InfoFi 与注意力激励](09-infofi.md) | 区分广义信息金融与注意力奖励，读懂 Mindshare、评分和激励设计的局限 |
| [DeSci、科研资助与知识产权](10-desci.md) | 理解科研资助、BioDAO、知识产权凭证与 AI 科研助手，区分资金热度和科学证据 |
| [可信执行环境与远程证明](11-tee-attestations.md) | 看懂证据、验证者和业务策略，解释硬件证明的边界 |
| [可验证凭证 · 签发、出示与撤销](12-credential-status-revocation.md) | 区分签名有效、声明真实、持有人绑定和业务可用 |
