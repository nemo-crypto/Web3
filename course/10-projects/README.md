# 练习、验收与术语

[课程首页](../../README.md) · [所有阶段](../README.md)

用模拟数据把钱包、兑换和支付串成可检查的交付物。

**适合** 全体读者

**阶段验收** 独立完成一项课程项目，提交状态图、测试用例和验收记录。
