# 期权、到期与产品损益

[课程首页](../../README.md) · [本阶段](README.md)

> **学完能做到**：对比现货、永续与期权在到期和价格波动下的现金流。

## 先看一个场景

小周想先约定将来买入某资产的价格，付出 5 作为这项权利的费用。到期时市场价变了，他需要判断这项权利值多少，以及扣掉先付的 5 后实际赚亏多少。

## 核心原理

先付的费用叫**权利金**，约定的价格叫**行权价**。对看涨期权，市场结算价比行权价高的时候，差额是到期内在价值。差额为零或负数时，价值按零算。看跌期权则看行权价高出结算价多少。最后用到期价值扣掉权利金和其他费用，得到买方净结果。

## 需要区分的概念

现货直接持有资产；永续主要承担价格、资金费和清算风险；期权还涉及期限、波动率与交易对手或合约规则。

## 先让四个价格说话

假设购买一份看涨期权需支付 5，行权价格为 110。到期时只看约定结算价与 110 的差。差额为正时有内在价值，再扣掉先付的 5。做练习时暂时忽略其他费用，标明数量为一份。

| 到期价 | 到期内在价值 | 净损益 |
| ---: | ---: | ---: |
| 90 | 0 | -5 |
| 110 | 0 | -5 |
| 115 | 5 | 0 |
| 130 | 20 | +15 |

在这个例子里，115 才是到期盈亏平衡点。到期之前的市场报价还可能包含剩余时间和预期波动价值。将「是否有行权价值」与「买方整笔是否赚钱」分开读，能避免把到期价值误当成到手收益。
