# 代币、稳定币与资产上链

[课程首页](../../README.md) · [所有阶段](../README.md)

识别不同资产的权利与发行机制，将链上支付落到订单和账务。

**适合** 产品与支付团队

**阶段验收** 能设计一张稳定币支付账单和完整的退款、对账流程。
