# 区块链与交易基础

[课程首页](../../README.md) · [所有阶段](../README.md)

理解数据、账户与交易如何组成账本，再比较不同链。

**适合** 初学者

**阶段验收** 能追踪一笔示例转账，解释地址、Gas、回执和最终性。

## 课程目录

| 课程 | 学习成果 |
