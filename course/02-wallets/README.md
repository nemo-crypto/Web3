# 钱包、身份与签名

[课程首页](../../README.md) · [所有阶段](../README.md)

从自托管和恢复开始，理解连接、登录、签名、授权及账户升级。

**适合** 用户与产品开发者

**阶段验收** 能画出钱包登录和代币授权的两条独立流程。
