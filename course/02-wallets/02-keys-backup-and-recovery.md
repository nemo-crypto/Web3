# 私钥、助记词与账户恢复

[课程首页](../../README.md) · [本阶段](README.md)

> **学完能做到**：识别钱包恢复材料、验证者与设备遗失时的流程。

## 先看一个场景

用户手机遗失，云端同步了登录凭证，钱包提供独立的链上恢复流程。应逐项确认恢复后能否控制原地址。

## 核心原理

私钥用于签名。助记词在相关钱包标准下可派生密钥，派生路径与可选口令也会影响结果。合约钱包还能依赖代理人或恢复规则。

## 需要区分的概念

私钥、助记词和恢复口令都属于控制凭证；地址是公开标识；登录身份用于账户认证；恢复角色可能拥有修改控制者的权力。

## 换手机时按顺序排查

先保存模拟旧地址，再走恢复步骤。恢复后先确认新设备里的地址与旧地址一致，然后查正确网络和资产。余额空白有几种可能：地址变了、查错网络、钱包没有加载该代币，或上次余额来自平台托管账户。逐项核对比反复导入凭据更容易查清。

| 你看到的情况 | 先查什么 |
| --- | --- |
| 地址相同，只有代币余额没显示 | 核对网络与代币合约，查同链浏览器 |
| 地址不同 | 查账户序号、派生路径、可选口令或钱包类型 |
| 登录恢复了，交易仍无法签名 | 查原钱包把登录、签名和恢复交给了哪一方 |
| 在另一台设备上还有访问权限 | 用练习账户确认怎样清理旧设备授权 |

练习只需记录模拟地址与恢复类型。把恢复材料保存在符合钱包说明的位置，避免把凭据当成客服核验资料。

## 动手练习

只在模拟账户演练。记录恢复类型、需要哪些设备或角色、多久能恢复，以及恢复过程中旧设备的授权如何撤回。

## 自测

同一组词恢复后余额为空，有哪些可先检查的原因？

<details>

检查网络、派生路径、账户索引和可选口令。最好核对历史地址，避免把不同账户当成余额丢失。
